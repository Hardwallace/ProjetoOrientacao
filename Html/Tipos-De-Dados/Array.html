Array

Em JavaScript, um Array é uma estrutura de dados usada para armazenar uma coleção de elementos em uma única variável. Esses elementos podem ser de qualquer tipo, como números, strings, objetos e até mesmo outros arrays.

Os arrays em JavaScript são indexados numericamente, ou seja, cada elemento tem um índice (posição) que começa do 0.

let numeros = [10, 20, 30, 40, 50];
// 10 - posicao 0; 20 - posicao 1;
// 30 - posicao 2; 40 - posicao 3;
// 50 - posicao 4;

let frutas = ["Maçã", "Banana", "Laranja"];

Cada item do array tem um índice, começando do 0.

let carros = ["BMW", "Audi", "Mercedes"];

Console.log(carros[0]); // "BMW" (primeiro elemento)

Console.log(carros[1]); // "Audi" (segundo elemento)

Console.log(carros[carros.length - 1]); // "Mercedes" (ultimo elemento)

Os arrays possuem vários métodos úteis para adicionar e remover elementos.

let lista = [1, 2, 3];

lista.push(4); // Adiciona final da lista
// Resultado = [1, 2, 3, 4]

lista.unshift(0); // Adiciona inicio da lista
// Resultado = [0, 1, 2, 3, 4]

Os arrays são extremamente úteis e amplamente usados em JavaScript para armazenar e manipular dados.
