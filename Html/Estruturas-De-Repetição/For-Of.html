For-Of

Itera sobre os valores de um objeto iterável (como arrays e strings).

O "For-Of" é uma estrutura de controle de fluxo introduzida no ECMAScript 6 (também conhecido como ES6) que é usada para iterar sobre elementos iteráveis, como arrays, strings, mapas, conjuntos, entre outros. Ele simplifica a iteração sobre esses tipos de dados, permitindo acessar diretamente os valores dos elementos, em vez de seus índices ou chaves.

for (variavel of iteravel) {
    // Bloco de código a ser repetido
}

A ‘variável’ é uma variável local que recebe o valor de cada elemento do iterável em cada iteração.

O ‘iterável’ é o objeto iterável sobre o qual você deseja iterar.

Um exemplo prático sobre o escopo explicado acima pode ser representado da seguinte maneira:

let numeros = [1, 2, 3, 4, 5];

for (let numero of numeros) {
    console.log(numero);
}

O loop ‘For-Of’ itera sobre o array numeros.

Em cada iteração, a variável número recebe o valor de cada elemento do array.

O valor de cada elemento é exibido no console. O loop for-of simplifica a iteração sobre os elementos do array, eliminando a necessidade de acessar os elementos por meio de índices.
