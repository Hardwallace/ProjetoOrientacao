Boolean

Em JavaScript, um Boolean é um tipo de dado que só pode ter dois valores: true (verdadeiro) ou false (falso).

Os valores booleanos são muito utilizados em estruturas condicionais, comparações e lógicas de controle de fluxo.

let verdadeiro = true;

let falso = false;

Console.log(preco, quantidade); // true

Console.log(preco, quantidade); // true

Os operadores de comparação retornam valores booleanos (true ou false):

Console.log(10 > 5); // true

Console.log(3 === 3); // true

Console.log(7 < 2); // false

Console.log("a" !== "b"); // true

Os booleanos são essenciais para controle de fluxo e lógica em JavaScript.
