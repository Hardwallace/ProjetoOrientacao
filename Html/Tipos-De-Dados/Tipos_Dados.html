String

Em JavaScript, uma string é um tipo de dado usado para representar texto. Strings são sequências de caracteres e podem ser definidas usando aspas simples ( ' ), aspas duplas ( " ) ou crases ( ` ) para template literals.

let mensagem1 = "Olá, mundo!";
// Aspas duplas

let mensagem2 = 'JavaScript é incrível!';
// Aspas simples

let nome = "Wallace";

// Demonstrar a variável em uma crase
let mensagem3 = `O nome escolhido é ${nome}`;
// Exemplo completo sobre a crase

As características das strings são as seguintes: as strings não podem ser alteradas diretamente, apenas substituídas por uma nova. Os métodos úteis são:

  • 📏 .length = Retorna o tamanho da string;
  • 🔠 .toUpperCase() = Converte para letras maiúsculas;
  • 🔡 .toLowerCase() = Converte para letras minúsculas;
  • 🔄 .replace("antigo","novo") = Substitui parte do texto;
let nome = "maria";
// Declarando variável

Console.log("O nome tem " + nome.length + " letras.");
// Exibe: O nome tem 5 letras

Console.log(nome.toUpperCase());
// Exibe: MARIA

Console.log(nome.toLowerCase());
// Exibe: maria

Console.log(nome.replace("maria", "Joao"));
// Exibe: Joao
