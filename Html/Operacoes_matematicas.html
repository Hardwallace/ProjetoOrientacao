Operações Matemáticas

É a execução de cálculos ou manipulações numéricas em uma sequência ordenada de instruções. Essas operações são fundamentais para realizar diferentes tipos de cálculos e processamentos numéricos em um programa.

Ocorre de forma direta, uma após a outra, sem nenhuma condição ou iteração envolvida. Cada operação matemática é uma instrução independente que é executada em ordem sequencial.

let resultado = expressao;

'resultado' é a variável onde o resultado da expressão será armazenado.

'expressao' é a expressão matemática que você deseja calcular.

Um exemplo prático sobre o escopo explicado acima pode ser representado da seguinte maneira:

let x = 10;
let y = 5;
let soma = x + y;
let multiplicar = x * y;
let divisao = x / y;
let subtracao = x - y;

Várias operações matemáticas são realizadas em uma sequência ordenada de instruções. Cada operação é executada de forma sequencial, uma após a outra, conforme definido na estrutura sequencial do código JavaScript. Os resultados das operações são armazenados em variáveis correspondentes (Soma, Multiplicação, Divisão e Subtração). O resultado impresso será:

Soma = 15;
Multiplicação = 50;
Divisão = 2;
Subtração = 5;
