Object

Em JavaScript, um Object (objeto) é uma estrutura de dados que armazena pares de chave-valor. Ele permite organizar dados de forma mais estruturada e flexível.

Os objetos são usados para representar entidades do mundo real, como um usuário, um carro, um produto, entre outros.

A forma mais comum de se utilizar o Object é da seguinte maneira:

let pessoa = {
    nome: "Wallace",
    idade: 26,
    profissao: "Desenvolvedor"
}; // Objeto com o nome pessoa

console.log(pessoa);
// Exibe todo o objeto

console.log(pessoa.nome);
// Exibe apenas o nome "Wallace"

console.log(pessoa["idade"]);
// Exibe apenas a idade "26"

Podemos acessar e alterar valores do objeto usando notação de ponto (.) ou notação de colchetes ([]).

let produto = {
    nome: "Notebook",
    preco: 3500,
    estoque: 10
}; // Objeto com o nome produto

produto.preco = 3200;
produto["estoque"] = 8;
// Alterando os valores do preco e estoque do objeto produto

console.log(produto);
// Exibe todo o objeto

console.log(produto.preco);
// Exibe o novo valor = 3200

console.log(produto.estoque);
// Exibe o novo estoque = 8

Podemos adicionar novas propriedades e também removê-las usando delete.

let aluno = {
    nome: "Joao",
    curso: "Matemática"
}; // Objeto com o nome aluno

aluno.nota = 9.5; // Adicionando nova propriedade

delete aluno.curso; // Removendo propriedade

console.log(aluno);
// O resultado será { nome: "Joao", nota: 9.5 }

Os objetos são essenciais em JavaScript, pois permitem armazenar e manipular dados de forma estruturada. Eles são a base para conceitos mais avançados como JSON, POO (Programação Orientada a Objetos) e APIs.
